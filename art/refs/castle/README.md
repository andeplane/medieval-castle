# Castle style references

Anders' style references (photos, not ours to publish, so not committed). Keep local copies here when running the art review; the project keeps the originals.

1. `01-gravensteen-moat-walls.png`: Gravensteen, Ghent. Walls rising straight from the moat, buttresses joined by tall blind arches, corbelled parapets.
2. `02-round-tower-grey-stone.png`: Windsor-style round tower in light grey stone, crenellated top, chimneys behind.
3. `03-square-towers-mountain.png`: Irish castle with square crenellated towers against a mountain.
4. `04-rubble-masonry-round-tower.png`: rubble masonry with a round tower and a round-arched gate.
